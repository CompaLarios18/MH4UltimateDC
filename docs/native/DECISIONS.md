# Decisions (native port)

The decision log for branch `native`. **Decided** entries were settled by the maintainer and change only if he says so. **Recommended** entries are the plan's default: work packages build on them, and a work package that finds a reason to change one stops and reports `needs-decision` instead of improvising. **Open** entries name the work package that settles them.

Only the orchestrator edits this file. To add or change an entry, add a row (or edit the status) in a batch PR, with the evidence linked, and say so in the PR description.
