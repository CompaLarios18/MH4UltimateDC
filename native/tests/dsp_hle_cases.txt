# The cases of the HLE DSP source oracle (N3-02): tools/native/dsp_oracle/dsp_oracle.py runs each of them
# against Azahar's own Source and writes native/tests/dsp_hle_expected.inc; native/tests/dsp_hle_test.cpp
# plays the same cases on mh4n::dsp_hle::Source and compares every frame. The format is in the script's
# docstring and docs/native/dsp.md. Every case is 200 frames unless it says otherwise; the audio is made by
